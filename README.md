🧠 Self-Control

This is a simple web article that talks about the importance of self contro in our daily lives. It has a fixed navigation bar, that turns dark as you scroll down to read the text in the lighter area. 

This project uses HTML5 for structure, CSS3 for styling and responsive design, and JavaScript (ES6) to create a scrolling based navbar effect. The navbar automatically changes color when the user scrolls to the article section, which provides a smooth and interactive experience.

Through this project, I practiced building full screen sections for articles and adding pictures, using CSS flexbox, creating navigation bars which are fixed in place, handling scroll events with JavaScript, and efficiently changing styles with CSS classes.

Future improvements include adding smooth scrolling, a mobile menu, dark mode, and additional website sections.
